# Ideas and scripts

- `ideas/` one file per idea, dated: `YYYY-MM-DD-slug.md` (template: ../templates/idea.md)
- `scripts/` one file per script, dated: `YYYY-MM-DD-slug.md` (template: ../templates/script.md)

A script that gets shot links to its video folder in `../../work/<slug>/`. An edit's captions are the spoken words from the footage, not the script text.
