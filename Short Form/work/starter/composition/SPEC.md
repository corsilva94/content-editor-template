# Starter composition

Generated by `../build.py`. Do not hand-edit `index.html` or `compositions/*.html`; change `edit.json`, `camera-plan.json`, `graphics.py` or the brand kit and run `npm run build`.

- Canvas 1080×1920. Footage on track 0, diagrams on track 1 (only when `graphics.py` returns scenes), captions on track 2, optional music bed on track 3.
- Footage transform comes from `camera-plan.json`: one neck anchor pinned to one screen point, scale only.
- Captions: one group per punctuation mark, two lines maximum, fixed position and size from `brand.json`. White with a thin dark edge over footage; ink colour over paper.
- Diagram scenes play over the cuts listed in `edit.json` `paper_cuts`, on a paper background with a 48px micro-grid. Drawing rules: `../../../notes/paper-grid-format.json`.
- Optional grade: put a HyperFrames media-treatment payload at `../color/selected-payload.json` and `npm run build` applies it to `#footage`.

Before export: `npm run check`, `npm run snapshot`, look at the frames at phone size, and compare against `../../../notes/short-form-safe-zones.json`.
