# Short Form job folder

One creator's work lives here. The root npm commands act on the video named in `../project.json`.

- `work/starter/`: the example video and the source every new video is copied from (`npm run new`).
- `work/<video>/`: one folder per video: `edit.json`, `camera-plan.json`, `graphics.py`, `build.py`, `composition/`.
- `work/brand-kit/`: `brand.json`, CSS, fonts.
- `work/paper-grid/`: a silent 15-second prototype of the paper-diagram style, useful as a reference while drawing.
- `content-brain/`: the creator's voice and facts. See `content-brain/README.md` to plug in yours.
- `notes/`: editing rules, safe zones, colour workflow, direction log.
- `exports/`: rendered MP4s (gitignored) and the safe-zone review overlay.
- `inbox/`: local source media, gitignored.
