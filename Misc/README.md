# Shared editing skills

The four core HyperFrames skills the renderer and the agent use: HyperFrames authoring, HyperFrames CLI, HyperFrames registry and media-use. The root npm commands install the renderer itself.

Optional skills or services mentioned inside these documents are not evidence that they are installed or connected here. The creator's `brand.json` and the rules in `Short Form/notes/` take precedence over generic examples in these skills.
